# Zingen 🎤

Landing page responsiva de um aplicativo de karaokê, desenvolvida com HTML e CSS durante meus estudos com a Rocketseat.

**Status:** finalizado.

## Sobre o projeto

O Zingen foi um projeto educacional em que pratiquei a construção de uma página para diferentes tamanhos de tela. Meu principal aprendizado foi entender melhor como usar **media queries** para adaptar o layout entre celular e desktop.

A página apresenta o aplicativo, seus recursos, planos e uma seção de download. O projeto é uma interface estática: as funções de karaokê, gravação, assinatura e download do aplicativo são apenas demonstrativas.

## Tecnologias

- HTML5
- CSS3
- Flexbox e CSS Grid
- Media queries
- Variáveis CSS

## Aprendizados

- Adaptar o layout para diferentes larguras de tela com media queries.
- Ajustar colunas, imagens, espaçamentos e tipografia conforme o tamanho da tela.
- Organizar os elementos da página com Flexbox e Grid.
- Reutilizar cores, fontes e espaçamentos com variáveis CSS.
- Dividir o CSS em arquivos para facilitar a organização do projeto.

## Seções da página

- Apresentação do Zingen.
- Informações sobre o aplicativo.
- Cards com os recursos apresentados pelo app.
- Comparação dos planos Básico, Premium e Família.
- Seção demonstrativa de download.

## Como visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/carlosleonello/Zingen.git
   ```

2. Abra a pasta `Zingen`.
3. Abra o arquivo `index.html` no navegador.

O projeto não precisa de instalação de dependências.
